# AWS VPC Architecture & Network Troubleshooting

## 📌 Overview
Designed and deployed a custom AWS VPC from scratch with full network architecture 
including public and private subnets. Performed hands-on network troubleshooting.

## ✅ What I Did
- Built a custom VPC with public and private subnets
- Configured Internet Gateway, Route Tables, and NAT Gateway
- Validated end-to-end outbound connectivity from private subnet
- Troubleshot subnet routing failure caused by missing route table entry
- Identified and fixed NACL misconfiguration — corrected inbound and outbound rules
- Understood and demonstrated the difference between:
  - **Stateful** behavior → Security Groups
  - **Stateless** behavior → Network ACLs (NACLs)

## 🛠️ Tools & Services Used
- AWS VPC
- Public & Private Subnets
- Internet Gateway (IGW)
- NAT Gateway
- Route Tables
- Network ACLs (NACLs)
- Security Groups

## 📄 Outcome
Successfully built a production-style VPC architecture and resolved real network 
issues related to routing and access control misconfiguration.
